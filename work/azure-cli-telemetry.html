Case study 01 · Developer tooling

Observability for AI-assisted CLI workflows

End-to-end telemetry across multiple AI tool handlers, released to UAT and paired with one filterable dashboard across environments and deployments.

Organization
Microsoft
Role
Software Engineering Intern
Period
Dec 2025 — Feb 2026
Stack
Python, OpenTelemetry, Grafana

Operational gap

AI-assisted command-line workflows create questions that ordinary logs cannot answer cleanly: where time is spent, how model use affects cost, whether responses remain useful, and how behavior changes across handlers and releases.

What I built

I implemented end-to-end Python and OpenTelemetry instrumentation for the Azure CLI Copilot handler, tracing command workflows across multiple AI tool handlers. One unified, filterable Grafana dashboard brought the resulting signals together across environments and deployments.

Signals covered

  • Trace command workflows across multiple handlers instead of observing only the outer request.
  • Capture latency, token use, errors, handler outcomes, and response-quality signals in one consistent model.
  • Filter the operational view by environment and deployment so comparisons stay useful during investigation.

Release

The instrumentation was released to UAT through pull-request review and CI. The dashboard supported reliability, performance, and cost analysis across the instrumented workflows.

Supporting contribution I also contributed a fix to an Ev2 deployment script while collaborating with a co-intern and the wider engineering team.
