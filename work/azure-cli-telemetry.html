The operational gap

Ordinary logs could not cleanly answer where time was spent, how model use affected cost, whether responses remained useful, or how behaviour changed across handlers and deployments.

What was instrumented

I implemented end-to-end Python and OpenTelemetry tracing for the Azure CLI Copilot handler across multiple AI tool handlers. Latency, token use, errors, outcomes, and response-quality signals fed one Grafana dashboard that could be filtered by environment and deployment.

UAT release

The instrumentation reached UAT through pull-request review and CI. The dashboard brought reliability, performance, and cost analysis into one operational view.
