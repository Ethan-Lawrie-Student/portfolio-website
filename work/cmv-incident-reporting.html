The reporting problem

Employees need a responsive way to submit structured reports and attachments, while operational teams need controlled storage and review across varied dealership and workshop environments.

Architecture and constraints

I designed the platform around customised SharePoint and Plumsail forms, Azure Functions as the API boundary, SQL Server for structured records, and Azure Blob Storage for attachments. That keeps interface behaviour separate from persistence and gives each data type an appropriate destination.

Planned rollout

The architecture was prepared for a planned rollout to more than 2,000 employees. At the point covered here, implementation and deployment remained ahead.
