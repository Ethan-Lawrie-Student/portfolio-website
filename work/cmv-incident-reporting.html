Case study 03 · Production systems

Incident reporting across forms, APIs, and data

An end-to-end operational system connecting a custom reporting interface to serverless APIs, structured data, file storage, and administrative workflows.

Organization
CMV Group
Role
Data Solutions Engineer
Period
Apr 2024 — Present
Context
Enterprise operations

Problem

Incident reporting crosses several kinds of data and several user needs: employees need a clear way to submit reports and attachments, while administrators need reliable records, efficient review, and controlled editing. The surrounding legacy environment also required integration rather than a standalone replacement.

Approach

I architected the system end to end. Plumsail SharePoint forms provide the reporting interface, with custom JavaScript for dynamic behavior. Azure Functions expose REST APIs for data loading and persistence, SQL Server stores structured incident records, and Azure Blob Storage handles attachments. An administrative dashboard supports server-side pagination and secure record editing.

Key decisions

  • Separate the form experience from persistence through a serverless API layer, keeping data access and business behavior out of the client.
  • Use distinct storage suited to each data type: SQL Server for structured records and Blob Storage for attachments.
  • Use server-side pagination in the administrative view so review remains manageable as the record set grows.

Result

The result is a connected reporting workflow spanning submission, dynamic data access, attachment handling, persistence, and administration. It replaced disconnected operational steps with an end-to-end system designed for maintainable integration.

In separate CMV workflow work, I also introduced a batch-processing strategy for the employee share registry that improved usage efficiency by 1,500%.

This case study uses an abstract architecture and intentionally excludes internal screens, identifiers, business rules, and sensitive data.

Technologies

  • Plumsail
  • SharePoint
